Keys are stored locally on this device and are only ever sent to the provider you select below. This extension has no server of its own.

This is a cross-checking aid, not a source of fact. A flagged sentence is not a false one, search results are not verification, and AI summaries can be confidently wrong. Read the sources and judge for yourself. Provided as is, with no warranty and no liability accepted.

Sources

The thermometer weighs each source by a short built-in tier list: wire services, public broadcasters, government and academic sites and fact-checkers count most, major outlets a little less, encyclopedias and unrated sites less again, and blogs and social posts least. That list is this project's own and is not a media-ratings service. Override it here.

Search (required)

Saved on this device until you change it. Claims are flagged for free; a search call is only spent when you press "Check sources" on a claim in the side panel.
Strips lead-in attributions such as "officials said that" and, for long sentences, searches only the distinctive words. Off until you have checked it helps: compare both forms on your own claims. That page uses the key saved here and caches results, so it spends a few search calls the first time and none after.
Adds academic terms to web searches and lists journal, university and science-agency results first. Also asks OpenAlex, a free scholarly index that needs no key, for peer-reviewed articles when you press "Check sources", shown in their own section with journal, year and citations. The claim is sent to OpenAlex only when you press that button.

Published fact-checks (optional)

Looks for verdicts already published by fact-checking organisations such as Snopes, PolitiFact and Full Fact, and shows them with the search results when you press "Check sources".
Free from Google Cloud: enable the Fact Check Tools API and create an API key. Most claims have no published fact-check, so expect this to be empty more often than not.

AI summary (optional)

Summarizes what the search results say about each claim. Leave on "None" to see raw results only.
Any OpenAI-compatible server on your machine, such as Ollama or LM Studio. Nothing leaves your computer, and no key is needed.
Chrome downloads this model the first time it is used, so the first summary may take a while. Brave has no equivalent extension API for its Leo assistant, so choose the local model option there instead.
