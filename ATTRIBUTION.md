### Where the data lives

Raw data sits in `classifier/train/raw/`, which is git-ignored. It is not
redistributed in this repository; download it yourself from the Zenodo record
above. The trained model exported to `classifier/model/model.json` is a derivative
work of this dataset and carries the same attribution in its `attribution` field.

### A note on scope

ClaimBuster labels whether a sentence is a **check-worthy factual claim**, not
whether it is true. The classifier trained on it inherits exactly that scope: it
decides what is worth checking, and never asserts a verdict. Verdicts in this
extension come from search results and the optional AI step, which see evidence
the classifier never does. Do not present its scores as truth ratings.

## Other services

The extension calls search and AI providers using **the user's own API keys**,
under whatever terms those users accepted with each provider. No data from those
services is redistributed here. Outlet lean estimates shown in the side panel are
generated by the user's chosen AI model and are labeled as estimates; this project
does not use, redistribute, or claim compatibility with any commercial media-bias
ratings service such as AllSides, Ad Fontes Media, or Media Bias/Fact Check.
